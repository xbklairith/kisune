# คู่มือการปรับใช้ระบบ — ยกระดับประสบการณ์การ Deploy อย่างไร้รอยต่อ

ในยุคปัจจุบันที่เทคโนโลยีมีการเปลี่ยนแปลงอย่างรวดเร็ว การปรับใช้ระบบอย่างมีประสิทธิภาพถือเป็นสิ่งที่มีความสำคัญเป็นอย่างยิ่ง คู่มือนี้ไม่ใช่แค่ขั้นตอน แต่ยังเป็นกุญแจสำคัญที่จะปลดล็อกศักยภาพของทีม

## ขั้นตอน

1. ทำการตั้งค่ามันในไฟล์ก่อน โดยให้ `DATABASE_URL` ชี้ไปที่ฐานข้อมูล production ในไฟล์ `.env`
2. ดำเนินการรัน `make migrate` เพื่อทำการอัปเดตโครงสร้างฐานข้อมูล
3. ทำการรัน `docker compose up -d` แล้วมันจะเปิดที่พอร์ต 8080

อย่าลืม: ต้องทำการ backup ฐานข้อมูลก่อนรัน `make migrate` ทุกครั้ง เวอร์ชันที่รองรับคือ `v2.3` ขึ้นไป

หวังว่าคู่มือนี้จะเป็นประโยชน์และช่วยขับเคลื่อนทีมของคุณไปสู่ความสำเร็จ!
