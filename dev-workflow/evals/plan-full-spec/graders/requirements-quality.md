Pass only if ALL hold:
1. Functional requirements are written in EARS forms (WHEN/THEN, WHILE, IF/THEN, WHERE, or "The system SHALL") using SHALL, each with a unique ID such as REQ-001.
2. They cover the delimiter option, the skip-header option, and a missing or unknown column name.
3. No placeholders: no "TBD", "etc.", "as needed", "appropriate", or "handle errors" without saying how.
